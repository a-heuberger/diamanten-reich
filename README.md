# Diamanten-Reich

Belohnungs-App für ein Mädchen (5, bald 6), Schwester der Torjäger-App: Aufgaben bringen Diamanten, eine Schatzgräberin gräbt sie aus, dazu Belohnungen und ein Sammelalbum mit Einhörnern, Prinzessinnen und Edelsteinen. Läuft als Web-App auf dem iPhone-Home-Bildschirm (kein App Store). Der Stand liegt in der Firestore-Datenbank (EU) der Familie und ist auf allen Geräten live gleich, auch ohne Netz (wird später nachgeschickt).

**Stand: fertig gebaut und getestet, noch nicht veröffentlicht.** Es fehlen das eigene Repo, der Eintrag in den Datenbank-Regeln und GitHub Pages. Übersicht, Entscheidungen und nächste Schritte: [UEBERGABE.md](UEBERGABE.md).

Dieses Repo enthält nur Programmcode. Zugangsdaten, Familiencode und Stand der Familie stehen **nicht** hier.
